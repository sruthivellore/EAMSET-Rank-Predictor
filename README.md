# EAMSET Rank Predictor

**EAMSET Rank Predictor** is a Python-based tool designed to help students estimate their expected rank in the AP EAMCET (Andhra Pradesh Engineering, Agriculture and Medical Common Entrance Test) examination. By entering your marks or score, you can quickly get an idea of your probable rank, making it easier to plan your college applications and counseling strategy.

---

## 🌟 Features

- **Simple Command-Line Tool:**  
  Enter your EAMCET marks and instantly receive a predicted rank.

---

## 🚀 Getting Started

### Prerequisites

- Python 3.x installed on your system

### How to Use

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sruthivellore/EAMSET-Rank-Predictor.git
   ```
2. **Navigate to the project folder:**
   ```bash
   cd EAMSET-Rank-Predictor
   ```
3. **Run the script:**
   ```bash
   python eamcet_rank.py
   ```
4. **Follow the prompts:**  
   Enter your EAMCET marks when prompted, and the script will display your predicted rank.

---

## 🧑‍💻 How It Works

- The script uses a simple formula or mapping (as defined in `eamcet_rank.py`) to estimate your rank based on the marks you provide.
- The logic can be easily customized or extended if you wish to update the prediction model with more recent data or a different mapping.
